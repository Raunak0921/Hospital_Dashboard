# 🏥 Hospital Data Dashboard

A **Streamlit-based interactive dashboard** for hospital data analysis.  
It allows you to upload raw data (CSV, Excel, JSON, TSV, PDF), automatically clean it, and generate KPIs and charts. You can edit, add your own columns, and customize charts. All changes are saved locally so you never lose work.

---

## 🚀 Features
- Upload multiple file formats: **CSV, Excel, JSON, TSV, PDF**
- Automatic data cleaning and deduplication
- Multi-hospital support (separate storage per hospital)
- Interactive KPIs and charts with **Plotly**
- Indian numbering system formatting (K, L, Cr)
- Local persistence (your edits are saved)
- Customizable columns and charts
